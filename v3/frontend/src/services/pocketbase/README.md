# services/pocketbase

Único punto de integración técnica del frontend con PocketBase.

Aquí se crearán:

- `client.ts`
- `auth.ts`
- `files.ts`
- helpers de colecciones cuando aporten valor

No se introducirán credenciales de superuser. El frontend trabajará siempre con las credenciales y permisos del usuario autenticado.
